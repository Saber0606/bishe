## 0. 这一步是干什么的（背景）

W7 是阶段 3 的最后一个工作包：在 WEC-Sim 里把 19 个体用 18 个刚性（Fixed）约束装配回一台完整平台，做时域仿真并提取各约束处的反力时程——这是阶段 4 横撑截面内力的输入。装配前必须先定一个建模口径：**粘性阻尼怎么加**。

AQWA / BEMIO 是势流方法，只能给出辐射阻尼，算不了粘性效应（摩擦、漩涡脱落）；而粘性阻尼在垂荡 / 纵摇共振附近对运动幅值影响显著，缺失会把共振响应算大。NREL/TP-5000-76773 表 5 给出了整台平台的粘性阻尼，但它是**整体刚体口径的一张 6×6 总账**；WEC-Sim 里阻尼逐体施加，总账不能逐体重复贴（会放大约 19 倍），也不能只贴在一个体上（阻尼力作用位置错误，且会污染作为阶段 4 输入的约束反力）。因此需要一条"分账规则"：把表 5 总量拆到 19 体，要求装配等效回整体时与表 5 对得上、各体份额物理上可解释。这与 W2 把总质量分账到 19 体是同一类问题。

## 1. 表 5 原值（已回源，不是从正文誊抄的约数）

来源：NREL/TP-5000-76773《Definition of the UMaine VolturnUS-S Reference Platform》p. 12，Table 5 "Viscous Damping Matrix"，PDF 原件在仓库 `references/`（2026-11-13 用 `pdftotext` 提取核对）。

|  | Surge | Sway | Heave | Roll | Pitch | Yaw |
|---|---|---|---|---|---|---|
| Surge | **9.225E+05** | 0 | 0 | 0 | **−8.918E+06** | 0 |
| Sway | 0 | **9.225E+05** | 0 | **8.918E+06** | 0 | 0 |
| Heave | 0 | 0 | **2.296E+06** | 0 | 0 | 0 |
| Roll | 0 | 8.918E+06 | 0 | **1.676E+10** | 0 | 0 |
| Pitch | −8.918E+06 | 0 | 0 | 0 | **1.676E+10** | 0 |
| Yaw | 0 | 0 | 0 | 0 | 0 | **4.798E+10** |

单位：平动对角 N·s²/m²，交叉项 N·s²/m，转动对角 N·m·s²（表题原注）。这是**二次阻尼系数**（力 ∝ |v|·v），不是线性阻尼。

关于表 5 必须知道的三点（同报告 p. 11–12 正文）：

1. **参考点在 SWL 的塔架轴线上**（"pressure … integrated with respect to the point concurrent with the tower's vertical axis and the SWL"），不是整体重心（CoG z = −14.94 m）。任何拆分后的重组都必须先把各体量输运到**同一参考点**再与表 5 对账，否则交叉项对不上。
2. **只跑了四个单自由度工况**：surge、heave、roll、yaw（单位速度 1 m/s 或 1°/s，OpenFOAM SimpleFoam 定常求解）。表中 sway 对角与 surge 相等、sway–roll 交叉与 surge–pitch 等值反号，这是**表中的事实**；报告未见独立的 sway 工况，因此 sway = surge 应理解为报告的对称假设（推断，非报告明文），不是独立实测值——引用时不得当作实测值。
3. **表 5 是势流之外的附加粘性部分**：与 HydroDyn 的线性辐射阻尼并用（OpenFAST 口径）。在 WEC-Sim 链路里，辐射阻尼来自 `.h5`，表 5 不得重复计入辐射阻尼；只补粘性二次阻尼。

## 2. "拆分"必须满足的条件

- (a) **总量守恒**：19 体按刚接装配等效回整体时，6×6 二次阻尼矩阵 = 表 5（对角 + 交叉项都要对，不是只对对角）。
- (b) **每体可用**：拆出的量要能填进 WEC-Sim 的每体设置（具体实现形式——每体二次阻尼矩阵还是 Morison 单元——在 W7 建模时按本地 WEC-Sim 版本核对，本稿不预先断言）。
- (c) **交叉项不能按面积拆**：交叉项（surge–pitch、sway–roll）是参考点力臂的产物，只能由输运定理产生（见 §3.4 做法），直接按面积分摊交叉项在物理上无意义。

## 3. 选项 A（草稿推荐，计划书建议的具体化）：平动对角按迎流投影面积拆，转动 / 交叉由输运产生

### 3.4 转动对角与交叉项：不按面积拆，按输运产生（W7 的待算步骤，不是本稿的假设）

做法：每体先取局部二次阻尼矩阵（平动对角取 §3.3 的值，转动局部量暂按该体自身尺度估算或置零——两种起点都要在 W7 记录中试算并比较），再用刚体输运 `Sᵀ·Bqᵢ·S` 把各体矩阵搬到**同一参考点**（先搬到整体 CoG，再按表 5 的参考点定义搬到 SWL 塔架轴线点）后求和；求和结果与表 5 的 roll/pitch 1.676E+10、yaw 4.798E+10 及交叉项 ±8.918E+06 对账。

- 若输运后的转动总量与表 5 相差在可接受带内（建议门槛：与 GATE-B 同口径，<1%——**门槛本身也待 Saber 定**，本稿不代定），直接采用，交叉项由输运自然产生，不另行分摊。
- 若相差超带，允许对转动自由度乘**单一标量系数**使总量对上，并把该系数写进记录（不得把系数藏进每体数值里 silently 调数）。
- 该步的算式与结果是 W7 的正式产出，本稿只定方法、不预填转动分配值——**转动分配值现在没有，写了就是编造**。

## 4. 选项 B（集中式，不拆）：表 5 作为整体刚接装配的一张矩阵

把表 5 原样作为二次阻尼矩阵，加在刚接装配的整体自由度上（例如挂在体 1 / 整体 CoG，输运到 WEC-Sim 参考点；参考点与 §1 第 1 点一致）。

- 优点：总量守恒是**构造性成立**的，零新增参数；GATE-C 的全局检查（自由衰减、规则波 RAO）与选项 A 在一阶意义上相同。
- 缺点：阻尼力作用点集中，**界面约束反力（阶段 4 的输入）会与分布式阻尼不同**——若阶段 4 的截面内力对阻尼分布敏感，B 会系统性地错估界面力；且无法反映各体阻尼差异。
- 适用：W7 时间紧、或选项 A 的输运核对失败时的退路。

## 5. 选项 C（Morison 标定，最物理、最重）：每体标定 Cd

每体按 Morison 单元给阻尼系数 Cd，用单自由度装配试验标定到表 5，并用 NREL 报告图 13–16 的自由衰减阻尼比曲线做独立验证。

- 优点：最贴近粘性机理；分布最真实。
- 缺点：工作量最大（每类体一个 Cd + 标定 + 衰减验证）；且 Morison 是二次（拖曳）阻尼、与表 5 的等效只在选定运动幅值下成立；Cd 与 §3.3 的面积份额不是一回事，不能互相代换。
- 适用：仅当 A/B 在 GATE-C 衰减验证中被证伪、或导师明确要求时才启动。
