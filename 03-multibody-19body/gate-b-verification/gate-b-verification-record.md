## 2. 关键约定发现：BEMIO 激励力相位约定（直接比对必然"对不上"，不是数据错误）

复核第一步发现：`.h5` 激励力**幅值**与 AH1 FORCERAO 在全部 19 体 × 25 浪向 × 47 频点 × 6 自由度上逐点一致（相对差中位 1.2×10⁻¹⁶），但**相位**逐分量不同。分解相位差后证实，`.h5` 采用 BEMIO 约定：

```
F_h5,b(ω,θ) = conj( F_AH1,b(ω,θ) ) · exp( −i·k·(x_b·cosθ + y_b·sinθ) )，k = ω²/g（深水）
```

其中 (x_b, y_b) 为第 b 体在 AH1 中的重心坐标。即 BEMIO 做了两件事：相位取共轭（约定差异），并把相位参考点由各体自身重心换算到全局原点。识别证据：抽出 γ_b(ω,θ) = ∠[F_h5 / conj(F_AH1)] 后与 −k·(x_b cosθ + y_b sinθ) 逐点比对，92,718 个掩膜点残差中位 0、p95 2.8×10⁻⁸ rad、最大 4.6×10⁻⁶ rad；有限水深色散（h = 200 m）版本残差 p95 2.0×10⁻² rad，被排除。

**给后续读者的警告**：把 `.h5`（或 hydro.mat 的 `ex_re/ex_im`）相位与 AQWA FORCERAO 相位直接逐点比对，会得到中位约 124% 的"误差"——那是约定未对齐，不是 BEMIO 出错。WEC-Sim 按 BEMIO 约定自洽地读取 `.h5`，无需任何改动。本复核的激励力比对均先按上式逆变换回 AH1 约定再进行。同理，hydro.mat 以 HDF5（MATLAB v7.3）存储，数组维度反转：`hydro.Ainf` 读出的矩阵是 MATLAB 内存中的**转置**，`hydro.A/ex_*` 等三维数组的维度序亦反转，读取时须先转置/换序（本复核已按此处理，并以运行日志打印的 Ainf 数值块定标核对无误）。

## 3. 复核结果

掩膜口径与 GATE-A 裁决一致：逐（浪向， 自由度）取 |F| > 该通道全频峰值 5% 的点计入统计。激励力先除归一化（BEMIO 以 ρg 归一化，ρ = 1025、g = 9.81，本复核按 ρg = 10055.25 还原量纲；该比值已逐分量验证为常数）。

### 3.1 激励力

| 比对 | 点数 | 幅值相对误差（中位 / 最大） | 相位误差（中位 / 最大） |
|---|---|---|---|
| 逐体：`.h5` 逆变换后 vs AH1 FORCERAO | 92,718 | 0 / 6.6×10⁻¹⁶ | ~0° / 0.00026° |
| 合成至整体重心（corr+）vs corr+ 锚，全谱 | 5,681 | 2.2×10⁻¹⁶ / **0.357%** | ~0° / **0.168°** |
| 同上，仅 ω ≤ 0.15 rad/s | 712 | 3.8×10⁻¹⁶ / 0.0018% | ~0° / 0.00038° |

- 判据判定：幅值最大 0.357% < 1%、相位最大 0.168° < 1°，**通过**。两个最大值都出现在 Mz 通道（浪向 120°；幅值点 ω = 1.85、相位点 ω = 1.15），且该点 |F| 仅为本通道峰值的约 5.6%——即 GATE-A 已注明的 Mz 相消残差病态区；其余通道为机器精度量级。
- GATE-A 遗留观察项（ω ≤ 0.15 低频力矩残差带）复查结论：该残差带在 `.h5` ↔ AH1 比对中**不复现**（同频段幅值最大误差仅 0.0018%），证实它源于 19 体分体模型与整体单体模型之间的差异（分体/网格口径），不是 BEMIO 引入的。论文局限性中仍应按 GATE-A 记录注明该带相对于整体模型的存在与量级（≤5.95×10⁶ N·m/m、约峰值 5%）。

### 3.2 附加质量 / 辐射阻尼矩阵（A、B）

`.h5` 的 `added_mass/all`、`radiation_damping/all` 组装为 114×114 后逐频与 AH1 的 ADDEDMASS / DAMPING 数据块比对（A 按 ρ、 B 按 ρω 还原量纲）：47 个频点中最大相对差（以各频峰值元素为尺度）A 为 6.6×10⁻²⁰、B 为 4.8×10⁻⁸（ω = 2.10，归一化往返舍入量级）。即 A、B 的读入与写出无实质误差。

### 3.3 Ainf（无穷频率附加质量）

- **处理方式确认**：运行日志中 readAQWA 后与 radiationIRF 后的两组 Ainf 打印值不同（如首块 A44 由 2.8068 → 3.7335，×10⁴ 打印标度），证实 radiationIRF 由辐射 IRF **重算**了 Ainf，而非沿用 AQWA 读入值——W5 注意事项中"LHFR 关闭、Ainf 待确认"一项就此闭合。
- **一致性**：`.h5` 各体 `added_mass/inf_freq` 与 hydro.mat 的 Ainf 逐元素一致（差 0.0，已计入第 2 节的转置关系）。
- **外部 sanity**：将 114×114 Ainf 刚体合成至静水面原点后与 NREL/TP-5000-76773 表 4 比对：A11 +1.30%、A33 −0.80%、A44 −0.99%、A55 −0.99%、A66 +2.24%、A15 +0.35%。表 4 是参考平台口径、非本门判据；偏差量级与 GATE 1A 既有偏差（≤1.8%）及 GATE-A 惯量偏差（Izz −1.42%）同量级，无异常指向。
- **数值观察（记录在案）**：radiationIRF 给出的 Ainf 非严格对称，整体对称性残差 1.58×10⁻³（相对最大元素）；个别耦合项的不对称相对其自身可达约 4.5%（如 A15 = 1656.5 与 A51 = 1583.4，归一化值）。WEC-Sim 按原样读取，本复核不做对称化处理；若 W7 装配后出现异常，先查此处。

### 3.4 结构项

- body 顺序：`.h5` 的 body1–body19 与 AH1 结构 1–19 一一对应，各体 `dof_start/dof_end` 依次为 1–6、7–12、…、109–114，无错位。
- 重心：19 体的 `properties/cg` 与 AH1 COG 逐位一致（最大差 0.0）。
- 静水刚度：各体 `linear_restoring_stiffness` 的 K33 求和后还原量纲为 4.460323×10⁶ N/m，与整体单体基准 4.46027×10⁶ 的偏差 +0.001%。
- 排水量：各体 `disp_vol` 合计 20,157.8 m³，AH1 合计 20,157.9 m³（−0.0005%，`.h5` 存储取整量级）。
