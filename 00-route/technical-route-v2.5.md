### 6.1 模型边界声明（论文必须写清）
- **校核对象**：阶段 4 提取与校核的是**下部三根矩形浮筒（pontoon，截面 12.5×7.0 m，跨度 `r ∈ [7.409, 45.416] m`）**共 **15 个截面**（每链 5 道：`I-0` 中心柱根、`I-1`、`I-2` 浮筒中点、`I-3`、`I-4` 外柱根）。
- **未建模斜撑边界**：上部 Ø0.9 m 径向斜撑（upper radial struts）未在 AQWA 网格与当前 16 体刚接/柔性铰拓扑中建模。因此所有通过立柱与浮筒传递的剖面载荷均由下浮筒承担（对下浮筒属偏保守估计），论文必须严格区分“下浮筒（pontoon）”与“上部斜撑”，不得混用术语或把下浮筒内力当成斜撑内力。

### 6.2 截面内力提取与转换口径
- **局部系内力向量** $\mathbf{f}_{\text{sec}} = [N,\; V_y,\; V_z,\; T,\; M_y,\; M_z]^T$：
  - 若已设置界面 `orientation`（局部 $x'$ 沿链径向向外、$z'$ 竖直向上、$y'$ 满足右手定则），关节处 `base` 作用在 `follower` 上的反力（或反向，由静水浮力自重净载符号校验确认）即为局部内力：$N = F_{x'}$（轴力，拉为正）、$V_y = F_{y'}$（水平剪力）、$V_z = F_{z'}$（垂向剪力）、$T = M_{x'}$（扭矩）、$M_y = M_{y'}$（垂向弯矩，使上下翼缘受拉/压）、$M_z = M_{z'}$（水平弯矩，使左右侧壁受拉/压）。
  - 若 `Fixed` 约束在全局系输出，必须按各链方位角 $\phi \in \{180^\circ, 60^\circ, 300^\circ\}$ 左乘二维平面旋转矩阵 $R_z(-\phi)$ 转换至上述局部系。
- **数据去瞬态与统计量**：每组时域仿真总长与去瞬态时间窗（如跳过前 `rampTime` 与初始瞬态至少 200 s，保留稳态规则波周期整数倍或不规则波至少 1,800–3,600 s 有效时程）；输出每个截面的 **均值（静水+稳态偏置）、标准差/RMS、正负幅值极值（Max / Min）**，定位控制截面（验证“1/2 截面 `I-2` vs 两端柱根 `I-0`/`I-4` 谁控制设计”）。

### 6.3 截面几何常数与应力校核公式
沿用 §9.3 同一空心矩形薄壁截面定义（外形 $B \times H = 12.5 \times 7.0\text{ m}$）：
- **主用壁厚**：$t_{\text{eq}} = 37.6\text{ mm}$（$A_s = 1.460\text{ m}^2$，$I_{\text{垂}} = 13.46\text{ m}^4$，$I_{\text{水}} = 32.43\text{ m}^4$，$J = 29.12\text{ m}^4$）。
- **壁厚下界包络（必做）**：因 $t_{\text{eq}}$ 将横隔板钢重摊入壳板使截面模量偏高，校核应力时必须同步给出 **$t = 30\text{ mm}$ 文献对照下界**的应力放大包络（按 §9.3 估算应力约高 25%）。
- **组合应力公式**：
  1. 矩形截面四角点最大正应力（$z_{\max} = \pm H/2 = \pm 3.5\text{ m}$，$y_{\max} = \pm B/2 = \pm 6.25\text{ m}$）：
     $$\sigma_{\max} = \frac{|N|}{A_s} + \frac{|M_y| \cdot (H/2)}{I_{\text{垂}}} + \frac{|M_z| \cdot (B/2)}{I_{\text{水}}}$$
  2. 薄壁闭口箱型截面最大剪应力（Bredt 扭转剪流 + 腹板/翼缘近似平均剪应力，保守叠加上限）：
     $$\tau_{\max} \approx \frac{|T|}{2 A_m t} + \frac{|V_z|}{2 H t} + \frac{|V_y|}{2 B t}, \quad A_m = (B-t)(H-t)$$
  3. Von Mises 等效应力：
     $$\sigma_{\text{eq}} = \sqrt{\sigma_{\max}^2 + 3\tau_{\max}^2}$$
- **强度校核基准（外部规范约定）**：NREL/TP-5000-76773 表 9 仅给出钢材 $E=2.00\times 10^{11}\text{ Pa}$、$G=7.93\times 10^{10}\text{ Pa}$、$\rho=7,850\text{ kg/m}^3$，**未给出屈服强度**。阶段 4 采用海工常用高强度结构钢 S355 / Q355（$\sigma_y = 355\text{ MPa}$，依据 DNV-OS-C101 / 船海钢结构规范，具体安全系数取 $\gamma_m = 1.15$ 或许用应力 $[\sigma] = \sigma_y / 1.5 \approx 236.7\text{ MPa}$ 作工程建议口径，论文中须明示外部规范出处）。

### 7.3 时域因果阻抗控制律设计（WEC-Sim 可实现路径）
理论复共轭最优控制 $Z_{\text{pto}}(\omega) = Z_i^*(\omega) = R_i(\omega) - i[\omega(M + A(\omega)) - K/\omega]$ 在时域为非因果系统且存在无功倒灌失稳风险。阶段 5 对比三条逐级控制档位（参数整定基准以**状态 A 全系统共振频率**与 WEC 浮子垂荡共振频率为准）：
1. **被动控制（纯阻尼对照档）**：$F_{\text{pto}} = -B_{\text{pto}} \dot{z}_{\text{rel}}$，扫描 $B_{\text{pto}}$ 找功率最优或减载最优点；
2. **因果可实现阻抗控制（PI 阻抗控制 / 次优反应控制）**：
   $$F_{\text{pto}}(t) = -B_{\text{pto}} \dot{z}_{\text{rel}}(t) - K_{\text{pto}} z_{\text{rel}}(t)$$
   其中允许 $K_{\text{pto}} < 0$（负刚度调谐，使 WEC 等效刚度向目标海况主频对齐以接近相位共振），但必须同时施加**工程可行约束**：
   - **稳性下限约束**：确保 $K_{\text{hydro,wec}} + K_{\text{pto}} > 0$ 且不引起平台纵摇静水稳性恶化；
   - **物理限幅与效率折扣**：设置 PTO 行程机械限位缓冲力（end-stop）与最大输出力饱和上限，并对双向无功功率流（负功阶段由储能侧向海浪释放能量）计入传动效率 $\eta_m$（如 0.85–0.90），防止出现脱离物理实际的高无功假功率。
3. **进阶频变/自适应逼近（可选精细路径）**：针对不规则波谱峰偏移，采用基于波浪谱峰频率在线/查表切换 $(B_{\text{pto}}(T_p), K_{\text{pto}}(T_p))$ 的增益调度阻抗控制，或带限幅的弱因果滤波近似控制。

### 7.4 四档剥离对照组与“三维互馈增益”量化公式
为严格区分“外柱新增 WEC 几何体带来的被动水动力改变”与“阻抗控制主动调控带来的增益”，**必须设立四档对照组**（替代原 V2.5 的三档）：
- **Baseline 0（无 WEC 原平台）**：纯 16 体状态 A 全系统平台+风机（代表原版 VolturnUS-S 性能基准）；
- **Baseline 1（WEC 机械锁死对照）**：19 体含 3 个 WEC 浮子但 PTO 用高刚度锁死或刚接于外柱（剥离 WEC 湿表面附加质量/绕射对平台运动与浮筒载荷的纯几何影响）；
- **Control P（被动纯阻尼 WEC）**：3 个 WEC 激活纯阻尼 PTO；
- **Control I（阻抗控制 WEC）**：3 个 WEC 激活 PI 阻抗控制（含对称统一整定 + 错位风浪下三柱独立/非对称整定讨论）。

**三维互馈增益指标定量定义**（以 Control I 分别对 Baseline 0 与 Control P 计算）：
1. **发电维度（风/浮体运动对波浪能捕获的互馈增益）**：
   - WEC 阵列平均电功率 $\bar{P}_{\text{wec}} = \frac{1}{T}\int P_{\text{elec}}(t)\,dt$、俘获宽度比 $CWR$；
   - 控制增益率 $\eta_{P,\text{ctrl}} = \frac{\bar{P}_{\text{wec}}(\text{Control I}) - \bar{P}_{\text{wec}}(\text{Control P})}{\bar{P}_{\text{wec}}(\text{Control P})} \times 100\%$（及有无风机气动阻尼下的 $\bar{P}_{\text{wec}}$ 差异，量化“风→浪”互馈）。
2. **运动抑制与风机侧维度（浪→风互馈增益）**：
   - 平台纵摇/垂荡 RMS 与极值降幅 $\eta_{\theta} = \frac{\text{RMS}(\text{Base}) - \text{RMS}(\text{Control})}{\text{RMS}(\text{Base})} \times 100\%$；
   - 风机侧代理/直接指标降幅：机舱前后加速度 RMS、塔基前后向弯矩 RMS 与极值、风机输出功率波动率（标准差/均值）降幅。
3. **结构载荷维度（下浮筒横撑截面减载/增载互馈效应）**：
   - 对 15 个浮筒控制截面（按阶段 4 同一应力公式与统计方法），计算等效应力与弯矩峰值/RMS 变化率 $\eta_{\sigma} = \frac{\sigma_{\text{eq}}(\text{Base}) - \sigma_{\text{eq}}(\text{Control})}{\sigma_{\text{eq}}(\text{Base})} \times 100\%$；
   - **重点核查减载边界**：按原纠偏五逻辑，分别统计共振海况、正常作业海况与高频区，明确哪些工况/截面实现减载、哪些参数或局部截面（如外柱根部 `I-4` 因 PTO 反作用力集中）会出现局部剪力/弯矩增大，避免“无条件减载”的片面结论。

### 7.5 阶段 5 最小工况矩阵（同步落地决策点 D1）
- **风浪同向主工况**：覆盖低风速（低于额定如 8 m/s）、额定风速（**10.59 m/s**）与高风速（切出前如 20 m/s）搭配对应联合海况（正常作业波高 $H_s=2\text{–}4\text{ m}$，$T_p=7\text{–}14\text{ s}$），0° 浪向。
- **错位风浪工况（D1 触发场景）**：固定 0° 风向 × 30° / 60° / 90° 波浪向，**不采用 120° 对称映射**，直接从 19 体模型的三条浮筒 15 道界面与 3 个外柱 WEC 分别提取独立数据，检验非对称受力与三柱独立阻抗整定的增益空间。

## 九、增补：浮筒分段界面柔性铰方案（技术细节，与 W7/阶段 4 衔接）

> **状态与定位**：本节依据 2026-11-23 方案（参照罗扬好、李良《计及水弹性变形的超大型风浪联合系统时域耦合分析》，*海洋工程* 44(2), 2026）保留全部技术参数，并按 V2.6 接入顺序：**先以 `Fixed` 刚接完成 GATE-C 关门，再切换本节 `Spherical PTO` 柔性铰完成回归/静力自检并决定是否作为阶段 4 主校核模型**。本节所有结构壁厚与刚度数值均为**等效反推估算值**，不得引为 NREL 原报告实测参数。

### 9.1 思路与运动学选型
- WEC-Sim 无有限元梁单元，等效做法是将 16 体 15 道界面连接由 `Fixed` 替换为**球铰（Spherical，约束 3 个平动、放开 3 个转动）**，通过弹簧刚度模拟浮筒弯曲/扭转柔性（子模块本身仍为刚体）。**严禁误选万向铰**（万向铰仅 2 个转动自由度、约束扭转）。阶段 5 的外柱 WEC PTO 为装置作动器，与本节结构铰严格区分、不得混用。

### 9.2 WEC-Sim 实现路线
- **路线 A（主用）：`Spherical PTO`（`ptoClass`）**：`constraintClass` 无刚度字段，球铰转动刚度必须挂在 `ptoClass` 的 3 个放开自由度上。**关键核查**：`stiffness` 默认为 0（不赋值会变成无弯矩机构且不报错）；必须在本地 WEC-Sim v7.1.0 核实 `Spherical PTO` 是否支持三轴各向异性 `[k_垂弯, k_水平弯, k_扭]` 赋值与局部轴对齐顺序。结构铰阻尼第一版取零，以免与表 5 `quadDrag` 耗散混杂；若后续增加结构阻尼，后处理须从发电吸收功率中剔除该 15 个结构 PTO 的耗散功率。
- **路线 B（备选对照）：Simscape Multibody `Bushing Joint`**：无逐自由度锁死功能，严禁用“无穷大刚度/阻尼”充当平动约束；若用于校验剪切/轴向变形影响，平动需赋予物理刚度（轴向 `3.07×10¹⁰`、垂向剪切 `4.39×10⁹`、水平剪切 `7.84×10⁹ N/m`，轴向弹簧模态约 179 rad/s）。

### 9.3 等效壁厚、刚度参数与敏感性（估算口径）
1. **等效壁厚反推**：锚定 W2 v2 单段浮筒钢重 `109.3 t`（不得用全平台均值 `381 kg/m²`）、壳板外表面积 `370.57 m²`（不含两端干切面），钢密度 `7,850 kg/m³`：
   $$t_{\text{eq}} = \frac{109{,}300}{7{,}850 \times 370.57} \approx 0.0376\text{ m} = 37.6\text{ mm}$$
2. **空心矩形截面常数**（$B\times H = 12.5\times 7.0\text{ m}$，$E = 2.00\times 10^{11}\text{ Pa}$，$G = 7.93\times 10^{10}\text{ Pa}$）：
   - $A_s = 1.460\text{ m}^2$，$I_{\text{垂}} = 13.46\text{ m}^4$，$I_{\text{水}} = 32.43\text{ m}^4$，$J = 29.12\text{ m}^4$；
   - $EI_{\text{垂}} = 2.69\times 10^{12}\text{ N}\cdot\text{m}^2$，$EI_{\text{水}} = 6.49\times 10^{12}\text{ N}\cdot\text{m}^2$，$GJ = 2.31\times 10^{12}\text{ N}\cdot\text{m}^2$。
3. **总柔度守恒铰刚度**（跨长 $L_{\text{跨}} = 38.007\text{ m}$，每链 5 道铰均分 $k_i = 5EI / L_{\text{跨}}$）：
   - $k_{\text{垂弯}} \approx 3.54\times 10^{11}\text{ N}\cdot\text{m/rad}$，$k_{\text{水弯}} \approx 8.53\times 10^{11}\text{ N}\cdot\text{m/rad}$，$k_{\text{扭}} \approx 3.04\times 10^{11}\text{ N}\cdot\text{m/rad}$。
4. **敏感性包络**：$t = 30\text{ mm}$ 时 $I/J$ 低 20.0%（截面应力高约 25%，作强度保守下界）；$t = 40\text{ mm}$ 时高 6.3%（同平台文献 CAD 对照）。

### 9.4 柔性铰检验顺序、步长与阶段 4 衔接
1. **验收顺序**：先 `Fixed` 刚接过 GATE-C → 再切换柔性铰先做 **`k×1000` 刚接回归自检**与**单铰静力 `Δθ = M/k` 自检**。
2. **步长复核（强制）**：铰弹簧局部模态约 **221 rad/s**，不可沿用刚接 `0.01 s`，需加密至 `≤0.001 s` 级做时间步长收敛检验。
3. **量级预期**：浮筒跨高比 `38.007 / 7.0 ≈ 5.4` 属粗短深梁，弯矩 $10^8\text{ N}\cdot\text{m}$ 量级下转角仅约 $3\times 10^{-4}\text{ rad}$。“定量证明刚体近似误差可忽略”或“捕捉局部弹性高频差异”均为有效科学结论。
4. **阶段 4 取数**：柔性版界面弯矩/扭矩由铰弹簧力矩 $M = k\cdot\Delta\theta$ 直接输出，轴力/剪力仍取约束反力；应力校核与 §6.3 共用同一壁厚 $t$ 定义。

### 9.5 WEC-Sim 拓扑与坐标连接规范（经官方 Code Structure 核对）
- **根体接地**：`Global Reference Frame` → `Floating (6DOF)` → `body(1)`（CEN）。严禁接地误用 `Fixed`（全锁死）或 `Floating (3DOF)`（仅允许平面 3 自由度，压死垂荡/横摇/纵摇）。
- **树形无闭环 + 一一对应**：Simulink 全部连接块（1 接地 + 15 界面 = 16 个）必须与输入文件 `constraint` / `pto` 对象数量、顺序、命名逐一对应；一处连接只放 1 个块（禁用 `constraint` + `pto` 双叠）；`base` 端一律朝向中央柱/全局根，`follower` 端背离。
- **局部系对齐**：每道界面按所属链方向单独设定 `orientation`（不得套用全局默认），使 `Rigid Transform` 将两侧体自重心系变换到同一界面点与同一局部方向。
