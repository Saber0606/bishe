     $$\sigma_{\max} = \frac{|N|}{A_s} + \frac{|M_y| \cdot (H/2)}{I_{\text{垂}}} + \frac{|M_z| \cdot (B/2)}{I_{\text{水}}}$$

### 7.3 柱内惯性式 WEC 时域因果阻抗控制律（针对 `nonHydro = 1` 修正）
由于内置振子为 `nonHydro = 1` 干质量块，**其静水恢复刚度 $K_{\text{hydro}} = 0$**（与外置浮子完全不同！），控制律必须包含**静重平衡 + 正基准调谐弹簧 + 阻尼/电抗阻抗调节**：
1. **静力平衡与基准刚度设定**：
   - 先抵消振子静重力 $m_{\text{osc}} g$（设定弹簧预压缩静平衡点 $z_{\text{rel}} = 0$），再配置基准机械恢复刚度 $K_{\text{spring}} > 0$，使振子固有频率 $\omega_{\text{osc}} = \sqrt{K_{\text{spring}} / m_{\text{osc}}}$ 对齐**状态 A 全系统纵摇固有频率（`0.036 Hz ≈ 0.226 rad/s`）**或主要波浪激励频率。
2. **三条逐级控制档位对比**：
   - **被动纯阻尼档（Control P）**：固定基准弹簧 $K_{\text{spring}}$，PTO 仅施加阻尼力 $F_{\text{pto}}(t) = -K_{\text{spring}} z_{\text{rel}} - B_{\text{pto}} \dot{z}_{\text{rel}}$，扫描 $B_{\text{pto}}$ 寻优发电或减载最优点；
   - **因果可实现阻抗控制档（Control I）**：在基准弹簧上叠加阻抗调谐刚度 $\Delta K_{\text{pto}}$ 与阻尼 $B_{\text{pto}}$：
     $$F_{\text{pto}}(t) = -(K_{\text{spring}} + \Delta K_{\text{pto}}) z_{\text{rel}}(t) - B_{\text{pto}} \dot{z}_{\text{rel}}(t)$$
     其中通过调节等效刚度 $K_{\text{eff}} = K_{\text{spring}} + \Delta K_{\text{pto}}$（可在线按波浪谱峰周期 $T_p$ 增益调度，等价于在基准调谐频率两侧做正/负刚度微调）与 $B_{\text{pto}}$ 实现惯性振子与平台运动之间的相位与阻抗匹配，但必须施加**三重工程硬约束**：
     1. **正刚度稳性护栏**：强制 $K_{\text{eff}} = K_{\text{spring}} + \Delta K_{\text{pto}} > 0$（否则 `nonHydro` 振子失去平衡位置直接撞缸）；
     2. **柱内几何行程限位（end-stop）**：结合外柱内部可用竖向净高（如最大允许行程 $\pm z_{\max}$）设置硬限位缓冲力与 PTO 最大输出力饱和上限；
     3. **双向传动效率折扣**：若 $\Delta K_{\text{pto}}$ 控制阶段出现能量短暂反流（负功），计入传动效率 $\eta_m$（如 0.85–0.90），防止虚高假功率。

### 7.4 四档剥离对照组与“三维互馈增益”量化公式
为严格剥离“质量切分改动”与“振子减摇+阻抗控制”带来的真实收益，设立四档对照组：
- **Baseline 0（原平台无装置，兼作阶段 4 基准）**：16 体状态 A 全系统，外柱质量 `1,731.90 t` 整体固结（无内部振子）；
- **Baseline 1（质量划转+PTO 刚性锁死自检）**：将质量 $m_{\text{osc}}$ 切分给 `body(17..19)` 但 `PTO` 刚性锁死（确认切分压载本身不改变平台动力学响应，作为纯物理一致性校验基准）；
- **Control P（被动调谐阻尼 TMD/WEC）**：3 个柱内振子启用被动基准弹簧 + 最优恒定阻尼 $B_{\text{pto}}$；
- **Control I（阻抗控制惯性式 WEC）**：3 个柱内振子启用因果阻抗控制 $(B_{\text{pto}}, \Delta K_{\text{pto}})$（讨论统一整定与随风浪错位/不对称工况三柱独立整定的差异）。

**三维互馈增益指标定量定义**（以 Control I 分别对 Baseline 0 与 Control P 计算）：
1. **发电维度（风/波引起平台晃动对柱内能量回收的互馈增益）**：
   - 3 柱内振子平均输出电功率 $\bar{P}_{\text{wec}} = \frac{1}{T}\int P_{\text{elec}}(t)\,dt$；
   - 阻抗控制功率增益率 $\eta_{P,\text{ctrl}} = \frac{\bar{P}_{\text{wec}}(\text{Control I}) - \bar{P}_{\text{wec}}(\text{Control P})}{\bar{P}_{\text{wec}}(\text{Control P})} \times 100\%$，及有无气动风载/气动阻尼下的 $\bar{P}_{\text{wec}}$ 差异（量化“风→平台摇晃→振子发电”互馈）。
2. **运动抑制与风机侧维度（振子阻抗控制→平台减摇→风机侧互馈增益）**：
   - 平台纵摇/垂荡 RMS 与极值降幅 $\eta_{\theta} = \frac{\text{RMS}(\text{Base}) - \text{RMS}(\text{Control})}{\text{RMS}(\text{Base})} \times 100\%$；
   - 风机侧指标改善：机舱前后加速度 RMS、塔基前后向弯矩 RMS 与极值、风机输出功率波动率（标准差/均值）降幅。
3. **结构载荷维度（下浮筒 15 截面减载/增载互馈效应）**：
   - 对下浮筒 15 个控制截面（按 §6.3 同一应力公式与统计方法），计算等效应力与弯矩峰值/RMS 变化率 $\eta_{\sigma} = \frac{\sigma_{\text{eq}}(\text{Base}) - \sigma_{\text{eq}}(\text{Control})}{\sigma_{\text{eq}}(\text{Base})} \times 100\%$；
   - **重点核查减载边界**：分别统计纵摇共振海况、正常作业海况与高频区，明确柱内振子反作用力对各截面（尤其是外柱根部 `I-4` 与中点 `I-2`）是减载还是局部增载，严禁写“无条件全面减载”。

### 7.5 阶段 5 最小工况矩阵（同步落地决策点 D1）
- **风浪同向主工况**：覆盖低于额定（如 `8 m/s`）、额定风速（**`10.59 m/s`**）与高于额定（如 `16–20 m/s`）搭配对应作业联合海况（$H_s = 2\text{–}4\text{ m}$，$T_p = 7\text{–}14\text{ s}$，0° 浪向）。
- **错位风浪工况（D1 触发场景，若时间允许作拓展对比）**：固定 0° 风向 × 30° / 60° / 90° 波浪向，**不采用 120° 对称映射**，直接从 16 体模型的三条浮筒 15 道界面与 3 柱内部振子分别提取独立数据，检验三柱独立阻抗整定的非对称减载潜力。

## 九、增补：浮筒分段界面柔性铰方案（可选增补校核，技术细节留存）

> **状态与定位**：本节依据 2026-11-23 方案（参照罗扬好、李良《计及水弹性变形的超大型风浪联合系统时域耦合分析》，*海洋工程* 44(2), 2026）保留全部技术参数。**按 V2.7 主线安排：主线全程以 `Fixed` 刚接完成 W7/GATE 1B 与阶段 4+5 对比；本节 `Spherical PTO` 柔性铰作为可选增补校核（若时间允许，取典型工况对比刚接 vs 柔性铰对 15 截面弯矩的影响）。** 本节所有结构壁厚与刚度数值均为**等效反推估算值**，不得引为 NREL 原报告实测参数。

### 9.1 思路与运动学选型
- WEC-Sim 无有限元梁单元，等效做法是将 16 体 15 道界面连接由 `Fixed` 替换为**球铰（Spherical，约束 3 个平动、放开 3 个转动）**，通过弹簧刚度模拟浮筒弯曲/扭转柔性（子模块本身仍为刚体）。**严禁误选万向铰**（万向铰仅 2 个转动自由度、约束扭转）。阶段 5 的外柱 WEC PTO 为装置作动器，与本节结构铰严格区分、不得混用。

### 9.2 WEC-Sim 实现路线
- **路线 A（主用）：`Spherical PTO`（`ptoClass`）**：`constraintClass` 无刚度字段，球铰转动刚度必须挂在 `ptoClass` 的 3 个放开自由度上。**关键核查**：`stiffness` 默认为 0（不赋值会变成无弯矩机构且不报错）；必须在本地 WEC-Sim v7.1.0 核实 `Spherical PTO` 是否支持三轴各向异性 `[k_垂弯, k_水平弯, k_扭]` 赋值与局部轴对齐顺序。结构铰阻尼第一版取零，以免与表 5 `quadDrag` 耗散混杂；若后续增加结构阻尼，后处理须从发电吸收功率中剔除该 15 个结构 PTO 的耗散功率。
- **路线 B（备选对照）：Simscape Multibody `Bushing Joint`**：无逐自由度锁死功能，严禁用“无穷大刚度/阻尼”充当平动约束；若用于校验剪切/轴向变形影响，平动需赋予物理刚度（轴向 `3.07×10¹⁰`、垂向剪切 `4.39×10⁹`、水平剪切 `7.84×10⁹ N/m`，轴向弹簧模态约 179 rad/s）。

### 9.3 等效壁厚、刚度参数与敏感性（估算口径）
1. **等效壁厚反推**：锚定 W2 v2 单段浮筒钢重 `109.3 t`（不得用全平台均值 `381 kg/m²`）、壳板外表面积 `370.57 m²`（不含两端干切面），钢密度 `7,850 kg/m³`：
   $$t_{\text{eq}} = \frac{109{,}300}{7{,}850 \times 370.57} \approx 0.0376\text{ m} = 37.6\text{ mm}$$
2. **空心矩形截面常数**（$B\times H = 12.5\times 7.0\text{ m}$，$E = 2.00\times 10^{11}\text{ Pa}$，$G = 7.93\times 10^{10}\text{ Pa}$）：
   - $A_s = 1.460\text{ m}^2$，$I_{\text{垂}} = 13.46\text{ m}^4$，$I_{\text{水}} = 32.43\text{ m}^4$，$J = 29.12\text{ m}^4$；
   - $EI_{\text{垂}} = 2.69\times 10^{12}\text{ N}\cdot\text{m}^2$，$EI_{\text{水}} = 6.49\times 10^{12}\text{ N}\cdot\text{m}^2$，$GJ = 2.31\times 10^{12}\text{ N}\cdot\text{m}^2$。
3. **总柔度守恒铰刚度**（跨长 $L_{\text{跨}} = 38.007\text{ m}$，每链 5 道铰均分 $k_i = 5EI / L_{\text{跨}}$）：
   - $k_{\text{垂弯}} \approx 3.54\times 10^{11}\text{ N}\cdot\text{m/rad}$，$k_{\text{水弯}} \approx 8.53\times 10^{11}\text{ N}\cdot\text{m/rad}$，$k_{\text{扭}} \approx 3.04\times 10^{11}\text{ N}\cdot\text{m/rad}$。
4. **敏感性包络**：$t = 30\text{ mm}$ 时 $I/J$ 低 20.0%（截面应力高约 25%，作强度保守下界）；$t = 40\text{ mm}$ 时高 6.3%（同平台文献 CAD 对照）。

### 9.4 柔性铰检验顺序、步长与阶段 4 衔接
1. **验收顺序（若启用可选增补校核）**：先按 V2.7 以 `Fixed` 刚接完成 W7/GATE 1B 与阶段 4+5 主线，再按需在典型工况下切换柔性铰做 **`k×1000` 刚接回归自检**与**单铰静力 `Δθ = M/k` 自检**。
2. **步长复核（强制）**：铰弹簧局部模态约 **221 rad/s**，不可沿用刚接 `0.01 s`，需加密至 `≤0.001 s` 级做时间步长收敛检验。
3. **量级预期**：浮筒跨高比 `38.007 / 7.0 ≈ 5.4` 属粗短深梁，弯矩 $10^8\text{ N}\cdot\text{m}$ 量级下转角仅约 $3\times 10^{-4}\text{ rad}$。“定量证明刚体近似误差可忽略”或“捕捉局部弹性高频差异”均为有效科学结论。
4. **阶段 4 取数**：柔性版界面弯矩/扭矩由铰弹簧力矩 $M = k\cdot\Delta\theta$ 直接输出，轴力/剪力仍取约束反力；应力校核与 §6.3 共用同一壁厚 $t$ 定义。

### 9.5 WEC-Sim 拓扑与坐标连接规范（经官方 Code Structure 核对）
- **根体接地**：`Global Reference Frame` → `Floating (6DOF)` → `body(1)`（CEN）。严禁接地误用 `Fixed`（全锁死）或 `Floating (3DOF)`（仅允许平面 3 自由度，压死垂荡/横摇/纵摇）。
- **树形无闭环 + 一一对应**：Simulink 全部连接块（1 接地 + 15 界面 = 16 个）必须与输入文件 `constraint` / `pto` 对象数量、顺序、命名逐一对应；一处连接只放 1 个块（禁用 `constraint` + `pto` 双叠）；`base` 端一律朝向中央柱/全局根，`follower` 端背离。
- **局部系对齐**：每道界面按所属链方向单独设定 `orientation`（不得套用全局默认），使 `Rigid Transform` 将两侧体自重心系变换到同一界面点与同一局部方向。
