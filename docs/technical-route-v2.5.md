## 四、阶段 2：浮筒切分与 AQWA 多体验证（GATE 2，一级已完成 2026-11-09）

1. **切分方案**：2 体方案 A——切 180° 迎浪浮筒，截面 x = -25.1 m；Body 2 = 180° 外柱 + 浮筒外侧段（**1,507 面元**，盒选规则），Body 1 = 其余（5,436 面元）；切面界面节点共 32 个。执行细则与元素清单见《阶段2_浮筒切分划分方案_V2》。
2. **干截面铁律**（保留融合版）：内部切面绝不生成 DIFF 面元；截面节点为 Body 2 复制一份，两子体不共用节点；外部湿表面不动。
3. **子体质量分配**：按压载/构件分布估算 + 守恒自检（初值：Body 2 ≈ 3,870 t、重心 ≈ (-42.8, 0, -14.1) m；Body 1 = 余量 13,984 t、重心由守恒反算 (11.84, 0, -15.17) m；子体惯量初值与合成守恒构造见划分方案 V2 §1）。
4. **GATE 2 验收（两级）**：
   - 一级（AQWA 内）：两子体系数先变换到同一参考点再求和（含互耦合项），与整体模型对比，目标值如下：

| 合成量 | 目标值（整体模型实测） | 容差 |
|---|---|---|
| 合成排水量 | 20,158 m³ | ≤2% |
| 合成 K33 | 4.460×10⁶ N/m | ≤2% |
| 合成 K55（水动力分量，同口径） | 2.201×10⁹ N·m/rad | ≤5% |
| 合成 A33（ω=2.10 rad/s） | 2.43×10⁷ kg | ≤5% |
| 垂荡固有频率 | 0.315 rad/s | ≤2% |
| 纵摇固有频率 | 0.466 rad/s | ≤2% |

   - 二级（WEC-Sim 内）：Fixed 约束刚接后 RAO/衰减与单刚体对比（并入 GATE 3）。
   - **一级实测结果（2026-11-09）**：合成排水量 +0.000%、K33 0.000%、K55 总刚度 -0.001%、A33@2.10 -0.000%、A55 全谱最大 0.005%、合成垂荡 0.3143 rad/s（-0.2%）、纵摇 0.4633 rad/s（-0.6%），全部远严于容差，一级通过；详见《GATE2_一级验收记录》。注意 LIS 逐结构打印的固有频率是单子体孤立口径，不可引为合成值。
5. 多体计算输出保留 `.AH1` + `.LIS` 同名配对（GATE 3 必需）。**注意：`.AH1` 不是默认输出**——它是 `.HYD` 二进制数据库的 ASCII 转印，dat 的 OPTIONS 行须含 **AHD1** 选项才生成（Aqwa Reference Manual §29.3.3）；二体 `.AH1` 已补跑并通过 BEMIO 数据块核对（2026-11-09，归档 #24）：GENERAL/COG/COB/排水量/质量惯量/静水刚度与 LIS 逐值一致，ADDEDMASS、DAMPING 各 188 条（四耦合块 ×47 频点）、FORCERAO 2,350 条（2 结构 ×25 浪向 ×47 频点）齐全。
6. **增补：单浮筒 4 段扩展（V2.5 新增，GATE 3 后执行）**：将 180° 浮筒由 2 段扩为 4 段——新增两道切口须落在现有网格环线上（约 x ≈ -16、-34 m，连同现有 -25.1 共 3 个截面），一次运行给出 3 截面的内力沿程分布，供阶段 4 定位控制截面（不默认跨中最危险）。四段质量仍按 R9 方法（压载分布估算 + 守恒反算 + 三笔账自检）分账；GATE 2 一级验收同法重跑（合成验算脚本按任意体数通用）。执行时机定在 GATE 3 链路以 2 体打通之后：方法已验证、改造成本低，先扩段只会把多体调试面与 WEC-Sim 建模风险叠加。
7. **决策点 D1：三根浮筒是否全切（V2.5 新增，全系统阶段决策）**：纯浮体阶段按口径速查第 5 条，只切一根足够且严格；全系统模型（阶段 5）若工况矩阵含固定风向×多浪向、或三柱 WEC 采用非对称阻抗整定，旋转映射失效，三根浮筒均须分段出截面力。届时 AQWA 侧按本节流程换分段重跑并自动验收，主要成本在 WEC-Sim 侧体数与约束数增加。本决策在阶段 5 建模前、工况矩阵冻结时作出，现阶段不预付成本。

## 五、阶段 3：BEMIO → WEC-Sim 多体约束建模（GATE 3）

（流程保留融合版，作三点补强）
- 前置：如需 IRF 在更高频段收敛，先细化网格再扩频至 3.00 rad/s，并复验网格可用上限；
- BEMIO `readAQWA` 读多体 `.AH1` + `.LIS`；注意 `.h5` 中 body 顺序须与 AQWA structure 编号（1=Body 1、2=Body 2）一致，WEC-Sim 中 bodyClass/constraintClass 手动搭建，Fixed 约束位置设在截面形心 (-25.1, 0, -16.5) m；
- 粘性阻尼（论文表 5 二次阻尼）在此阶段引入 WEC-Sim；以自由衰减 + 规则波复核刚接模型（GATE 2 二级验收在此完成）。
- GATE 3 判据（保留融合版）：刚接多体模型 6-DOF 运动与单刚体模型/AQWA 高度重合；约束反力 6 分量时程正常输出。
- **实测备忘（V2.5 新增，2026-11-09）**：
  1. `.AH1` 须由含 AHD1 选项的运行输出（见 §四第 5 条，已解决）；扩频重跑时在 OPTIONS 一并加 **LHFR**，补 FIDD 无穷频率附加质量——现 `.AH1` 该值为零，BEMIO 生成 `.h5` 时须确认其 Ainf 处理方式；
  2. **激励力相位约定**：AQWA 多体输出的激励力相位以**各结构自身重心**为基准（非全局原点），直接复数相加在顺浪向可差 87%。BEMIO 生成 `.h5` 后为 **GATE 3 必查项**：按《GATE2_一级验收记录》的相位修正方法复核 `.h5` 合成激励力与整体模型的一致性，不得默认 BEMIO 处理正确；
  3. 两体 `.LIS` 中的 RAO 为两独立自由体的口径，不是刚接系统 RAO，勿直接引用（二级验收以 WEC-Sim 刚接模型为准）。

## 六、阶段 4/5 与时间表

- 阶段 4（截面内力 → 梁截面应力校核）：保留融合版公式与统计方法。顺序：先以现跨中截面（x = -25.1 m）走通"约束反力 → 截面内力 → 应力校核"全流程；单浮筒 4 段扩展（§四第 6 条）完成后，以 3 截面内力分布定位控制截面并复核之。方案 B 增补（中心柱根部、外柱根部截面）仍为选做，视阶段 4 结果与时间决定。
- 阶段 5（**核心章：WEC 阻抗控制与风浪互馈增益**，V2.5 细化）：
  - **定位**：正式题目的核心问题——外柱加装 WEC 后，风、浪两子系统互馈增益的量化，以及 WEC 的 PTO 阻抗控制整定。保留融合版快速/精细两条路径与对比矩阵框架。
  - **全系统模型升为必需**：互馈增益的风机侧指标（塔基弯矩、机舱加速度等）离不开状态 A 模型；可借 `WEC-Sim_Applications/MOST` 框架搭建，水动力仍以本路线 AQWA 链为准（MOST 默认 NEMOH 数据仅作对照）。若时间不足，风机侧受益可先以平台运动抑制为代理指标，论文中须声明口径。
  - **阻抗控制**：PTO 等效为可调阻抗（阻尼 + 刚度），按阻抗匹配（复共轭）原理整定至机组共振附近最优；整定频率以全系统模型共振频率为准（全系统纵摇 0.036 Hz ≠ 纯浮体 0.0742 Hz，见 R11）。WEC-Sim 实现：快速路径用 PTO 阻尼/刚度参数扫描逼近最优阻抗；精细路径引入相位/速度反馈近似最优阻抗曲线。对照组三档：无 WEC / 被动（纯阻尼）/ 阻抗控制。
  - **互馈增益指标（三维）**：① 发电：WEC 平均吸收功率、俘获宽度比；② 运动抑制（浪→风受益）：纵摇/垂荡响应与统计量降幅，进而塔基弯矩、机舱加速度降幅；③ 结构载荷：横撑截面内力/应力降幅，与阶段 4 同口径截面、同统计方法对照。注意融合版纠偏五结论：减载非无条件成立，共振区与高频区须分开看，参数不当可增大局部剪力/扭矩。
  - **工况矩阵**：风浪同向扫向 + 固定风向×多浪向（错位风浪）两类；工况矩阵冻结时同步触发决策点 D1（§四第 7 条）：含错位风浪或非对称控制时，三根浮筒均须分段。
- 时间表（按实际进度重排）：阶段 0/1A 已完成（第 1–2 周实际已达成）；第 3–4 周阶段 2（切分 + GATE 2 一级，已于实际第 2 天完成，含 AH1 核对）；第 5–6 周阶段 3（BEMIO+WEC-Sim+GATE 3，含 GATE 2 二级）；其后做单浮筒 4 段扩展并重跑一级验收（约 1 周内并行量）；第 7–9 周阶段 4；第 10–12 周阶段 5（核心章，含全系统模型搭建与阻抗控制整定，工作量为全程最重之一）；第 13–14 周论文撰写与答辩准备。
