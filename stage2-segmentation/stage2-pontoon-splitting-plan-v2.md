## 〇、V2 复核结论：V1 有 3 处实质错误（本版已修正）

| # | V1 的问题 | 怎么发现的 | V2 修正 |
|---|---|---|---|
| 1 | **选元规则有系统性遗漏**：V1 用「方位角 171°~189° + 半径 ≤45.6 m」选浮筒段，把浮筒的**侧面条带**（侧面元质心方位角达 ±10.1°，超出 ±9° 容差）和**柱根过渡面元**排除在 Body 2 之外——Body 1 会包含嵌在 Body 2 区域内部的面元片，两体几何交错 | 全模型逐元复算 + 两体共享节点检查：V1 规则下两体共享节点散布在 x = −50.5 ~ −25.1 的整个区域（不止切面） | 选元规则改为**盒选**（见 §1），修正后两体共享节点**恰好 32 个、全部落在切面矩形边线上**（x = −25.15 ~ −25.09），两体只在切面相接 |
| 2 | **子体质量/重心随之失真**：V1 的 Body 2 排水体积少算约 670 m³（3,672 → 实为 4,341 m³），质量初值 3,260 t 偏低 | 按修正规则重算体积与构件分布 | m₂ = **3,870 t**、CoG₂ = **(−42.8, 0, −14.1) m**；Body 1 由守恒反算（见 §1 参数表） |
| 3 | **子体惯量缺失**：V1 只说"跑前补算"，没给值、没给方法， Deck 04 无法落笔 | 本次补算 | 两构件法粗估 Body 2 自身惯量 + **守恒反算法**定 Body 1 惯量（合成量恒等于整体模型，见 §1）；此项为全套初值中不确定性最大的一项（约 ±10% 量级），靠 GATE 2 二级验收再校准 |

另外复核确认无误、V2 沿用的 V1 结论：切 180° 浮筒、截面取现有网格线 x = −25.1 m、切面不建面元、外部湿表面不动、原文件不修改。

**一个诚实的提醒（不确定性）**：m₂ 初值对「压载分布假设」敏感。若压载（固定 2,540 t + 流体 11,300 t）按浮筒长度分配 → m₂ ≈ 3,900 t；若按总体积均匀分布 → m₂ ≈ 4,410 t。本版取两法中值偏下 **3,870 t（不确定带 ±300~500 t）**。注意：GATE 2 一级验收比的是**合成量**，由守恒构造保证恒等，**不受分配误差影响**；分配误差只影响两子体各自的局部动力学，留待 GATE 2 二级（WEC-Sim 刚接 RAO/衰减）与 GATE 3 时校准。

## 一、切分定义与参数总表

**切法**：将 180° 方位的外柱 + 其浮筒外侧段划为 Body 2，其余全部为 Body 1；两体在浮筒跨中附近 x = −25.1 m 的截面处分开。

**选元规则（V2 盒选规则，全模型逐元判定，质心记为 (cx, cy, cz)，柱轴为 (−51.75, 0)）**，满足其一即 Body 2：
- 柱体规则：质心到柱轴距离 < 6.35 m，且 cz > −20.01 m（180° 外柱全部，含水上部分）；
- 浮筒规则：−20.01 ≤ cz ≤ −12.99 m（浮筒高度带），且 |cy| ≤ 6.35 m，且 −58.0 < cx < −25.1 m。

## 三、路径 B 操作步骤（直接改 dat）

> 工具：任意文本编辑器（建议 VS Code 或 Notepad++，**关自动换行、显示列号**——Deck 03 是固定列格式）。每步做完在《GATE2_分段实施检查表》上打勾。

**B1. 复制底稿**
- 操作：把 `futi_lowfreq.dat` 复制为 `futi_2body.dat`，在新文件上改；原文件只读保留。
- 效果：得到与已验证整体模型逐字相同的底稿，GATE 2 对照基准不被污染。
- 产出：`futi_2body.dat`（初始与原文件字节一致）。

**B2. Deck 01 加节点（共 34 个）**
- 操作：在 `*END OF DECK 01*` 之前插入：
  - 节点 `99997`：(11.840, 0.000, −15.170) ← Body 1 的重心节点（新）；
  - 节点 `99998`：(−42.800, 0.000, −14.100) ← Body 2 的重心节点；
  - 节点 `20001`–`20032`：32 个界面复制节点，坐标与原界面节点完全相同（编号对应关系见《阶段2_界面节点清单.csv》）。
  - 行格式照 Deck 01 现有 NOD5 行复制后改编号与坐标（如 `    01NOD5  99998    -42.800     0.000   -14.100`，以现有行列宽为准）。
- 效果：两个子体各有自己的质量作用点；切面两侧各有一套节点，为"两体不共用节点"做准备。
- 检查点：Deck 01 节点总数 = 6,982 + 34 = 7,016 行节点记录。

**B3. Deck 02 改元素归属（1,507 行）+ 换界面节点号**
- 操作：对《阶段2_Body2元素编号清单.csv》中的 1,507 个元素行：
  1. 结构号字段 `(1)` 改为 `(2)`（行首 `02QPPL DIFF (1)(...)` → `(2)(...)`）；
  2. 若该行引用了界面节点（32 个之一），把节点号换成对应的 20001–20032 复制号（映射见界面节点清单）。只换 Body 2 行里的，Body 1 行里的原号不动。
- 效果：1,507 个面元正式归属结构 2，且切面两侧节点自此完全独立——这是 AQWA 把它认作两个独立浮体的关键一步。
- 检查点：全文检索 `(2)(` 的面元行数 = 1,507；抽查 3 个含界面节点的 Body 2 元素，确认引用的是 200xx 号。

**B4. Deck 02 改/加 PMAS 元素（质量挂载）**
- 操作：
  1. 原 PMAS 行 `#6944`：`02PMAS (1)(99999)(1)(1)` → 改为 `02PMAS (1)(99997)(1)(1)`（Body 1 的质量改挂到它自己的重心节点 99997；原 99999 不再被引用，可留置不管，AQWA 会忽略未引用节点或给无害警告）；
  2. 新增一行 `#6945`：`02PMAS (2)(99998)(2)(2)`（Body 2 质量挂到 99998，引用材料 2），编号紧接 6944、位于 `*END OF DECK 02*` 之前。
- 效果：两个结构各挂一份点质量，质量数值由 Deck 03 材料给出。
- 检查点：Deck 02 共有 2 行 PMAS，结构号分别为 (1)、(2)。

**B5. Deck 03 改/加材料（质量数值，固定列格式！）**
- 操作：
  1. 材料 1 行：数值由 `1.7854E+07` 改为 **`1.3984E+07`**（Body 1 质量 13,984 t）；
  2. 新增材料 2 行：数值 **`3.8700E+06`**（Body 2 质量 3,870 t）。

     `    03             11.3984E+07`
     `    03             23.8700E+06`
- 效果：两子体质量就位，合计 1.3984E+07 + 3.8700E+06 = 1.7854E+07，与整体模型总质量严格一致。
- 检查点：用编辑器的列选择/标尺功能确认两行第 20 列是材料号、第 21 列起是数值——**这是整套改动里最容易出错的一步**（融合版路线的"笔误"疑似正源于把两个字段连读）。

**B6. Deck 04 改/加惯量（PMAS 惯量行）**

## 五、AQWA 求解：运行设置与产出文件

- 操作：在 AQWA-Line 中以 `futi_2body.dat` 为输入运行（命令行或 Workbench 读取 dat 均可）。Deck 00 的 `RESTART 1 3` 沿用整体模型设置（Stage 1–3：静水+衍射/辐射全算），Deck 06/07/08 不动。
- 预期运行行为：求解器应识别出 **2 个结构（Structure 1 / 2）** 并分别输出各自的水动力系数与耦合项；若 LIS 里只有一个结构，说明 B3/B4 某步没生效，回 §七排查。

| 文件 | 内容 | 用途 |
|---|---|---|

## 六、GATE 2 一级验收：操作步骤与记录表

**原理**：两子体本是同一刚体拆开的，AQWA 对两体算出的系数（变换到同一参考点后）求和，必须复现整体模型的结果。合成对不齐 → 切分或 Deck 改动有错；对齐 → 切分在水动力层面无损。

**步骤**：
1. 从 `futi_2body.LIS` 抄录两结构各自的：排水体积、浮心、静水刚度矩阵（绕各自重心）、附加质量（绕各自重心，取 ω = 0.5 / 1.0 / 2.10 rad/s 三个频点抽查或全频段）；
2. 用参考点变换公式把两体的刚度/附加质量都换算到**整体重心 (0, 0, −14.94)** 处再逐项相加（刚度含静水项按同一口径；附加质量的平移公式与 GATE 1 换算 A55 时所用相同：平移距离取各子体重心与整体重心之差，耦合项按 A'i'j' = Aij + … 的标准形式，写论文时给出公式）；
3. 合成排水量 = 两体排水体积直接相加；合成固有频率由合成后的 (K, M+A) 按 GATE 1 相同方法解出；
4. 与下表目标值逐项比对，偏差超容差 → 按 §七排查，不要放行进 GATE 3；
5. 验收记录归档（建议另存 `GATE2_一级验收记录.md`，模板即下表）。
