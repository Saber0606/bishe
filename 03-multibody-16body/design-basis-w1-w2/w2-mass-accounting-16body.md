## 2. 分配规则（先验给定，不拟合逐体目标）

逐体几何量（排水体积 V、浮心、表面积、表面积形心）全部取自 W1 实测表。各构件的放置与形状模型如下：

- **固定压载**：846.67 t/外柱，置于柱底成块。密度取铁矿石混凝土 3.5 t/m³（设计假设）→ 每柱 241.9 m³，按外柱截面 π×6.25² = 122.72 m² 折合块高 1.97 m，z ∈ [−20, −18.03]，形心 (柱轴, −19.01)。
- **流体压载**：浮筒内自底向上灌注，灌注率 φ（同一 φ 适用于三条浮筒，内部容积以排水体积近似，薄壳口径）；浮筒容积之外的余量等分入三根外柱柱底，叠在固定压载块之上（截面 122.72 m²，自 z = −18.03 向上）。
- **结构钢**：基准按各体**表面积比例**分配（壳板口径），钢重心取该体表面积形心（W1 实测，含水上部分表面——钢分布本就及于水线以上）。
- **塔架接口**：100 t 点质量，置于 (0, 0, +15)。
- **逐体自身惯量形状模型**：浮筒段 = 实心盒 9.50175 × 12.5 × 7.0 m（钢与压载合并按总体质量计）；外柱钢 = 圆柱壳 R6.25 × 高 35 m，固定/流体压载块 = 实心圆柱（各自高度）；中央柱钢 = 圆柱壳 R5 × 高 35 m，塔架 = 点质量。逐体惯量由构件惯量按平行轴合成到该体重心。

## 3. 账目闭合（未知量与解法）

来源数据只给总量与构件构成，逐体钢重份额与灌注率 φ 在规则内仍有自由度。闭合方法（明示）：以钢重三类份额（中央柱 / 外柱 / 浮筒段，三链对称）与 φ 为未知量，方程为 Deck 03/04 的三笔账——钢重总量 3,914 t、总重心 z = −14.940 m、总惯量 Izz = 2.367×10¹⁰ kg·m²；在满足三方程的解中，取**与表面积比例基准偏离最小**者（最小修正原则）。Ixx / Iyy 不参与闭合，留作独立核查（§5）。

闭合结果：

注（闭合的主要假设，须明示）：三笔账要求中央柱的钢重约为表面积比例的两倍——物理上对应塔架接口支撑结构与三条浮筒根部节点加强集中在中央柱（这些内部加强不体现在外表面面积上）。这是闭合解中最大的单项修正，其合理性只能由量级判断（中央柱单位面积 742 kg/m² 偏高但未出格），**不是源文件给出的数值**；论文叙述分账方法时须按本节口径说明，不得写成原始分账。若后续取得更细的构件质量资料，应以其替换本闭合。

## 6. 诚实边界与待实跑项

1. 本表是**设计值**：逐体（质量、重心、惯量）三元组由 §2 规则 + §3 闭合产生，是 W3 的填卡依据；16 体实跑的逐体值只能由 16 体运行本身给出。W5 以实跑 AH1 重做三笔账，偏差 >0.5%（质量/重心）或 >2%（惯量）即回溯分账。
2. **逐体钢/压载再分拆不是源文件数据**：总量方程只约束各体总和与总账，满足三笔账的逐体分拆不唯一；本表取的是"规则 + 最小修正闭合"的一组解（§3 注）。论文叙述分账方法时按 §2–§3 口径，不得把构成分账写成原始分账或实测值。
3. 假设清单（均已在 §2–§3 明示，汇总备查）：浮筒内部容积 ≈ 排水体积（薄壳）；固定压载密度 3.5 t/m³（密度在 3.2–3.8 间变化时其形心 z 仅移动 ±0.09 m，对总账影响 <0.02%，不敏感）；钢重心 = 表面积形心；逐体惯量形状模型（盒/圆柱壳/实心圆柱）——总惯量由平行轴项主导，形状模型误差对三笔账的影响已由 Ixx/Iyy 独立核查界定在 0.7% 量级。
4. 与 W1 的衔接：排水体积、浮心、面元数以 W1 实测表为准（几何量，不由分账决定）；W3 v2 组装后已以 dat 逐体复算排水体积：逐段与 W1 表偏差 ≤0.69%（环界残差，见 `03-multibody-16body/w3-dat-assembly/` 核查记录）；W4 后 LIS 逐结构排水量按同一口径复核，偏差即切分保真度的直接证据。
